The safety-inspection procedure (applies everywhere) SAME ACROSS STATES

IFGC/IFGS Appendix C (or NFPA 54 Annex G in the four NFPA-54 states) — before touching the equipment, take an ambient reading: read the official text →

Ambient readingRequired action
CO ≥ 70 ppmEvacuate occupants, evacuate yourself, call 911
CO 30–70 ppm (traced to a fixed appliance)Shut the appliance off, tell the occupant it needs service before reuse
Combustible gas ≥ 20% LELEvacuate, call 911

Standing duty underneath all of it: find a condition that could make the appliance operate unsafely at any point → shut it off, tell the owner. Find a gas leak that could be unsafe → tell the owner, call the gas utility to shut off supply.

The classification itself — why this is "unsafe equipment," not a personal opinion — comes from two places worth showing a homeowner directly: IPMC \u00a7108.1.2, Unsafe Equipment → and IMC \u00a7108, Unsafe Mechanical Systems → (this one calls it a "public nuisance" outright, and Wisconsin\u2019s own code uses this exact language).

Who\u2019s actually authorized to physically shut off gas/electrical service varies by jurisdiction — some codes route that authority through a code official or the utility rather than the private technician. Worth confirming state by state with Sila legal/compliance before treating "I\u2019ve already shut off the gas and electrical" as accurate everywhere. (Narrower than it sounds: isolating the unit you're servicing at its own valve/breaker is standard technician scope everywhere \u2014 it's the formal condemnation/placarding act and utility-level disconnection that the code routes through an official.)

None of the text above is reproduced from the codes themselves — these are paraphrases with links to the real, current, official source. Use the links, not this summary, when showing a homeowner.
